# ☕ Premium Coffee Shop - Responsive Website

A modern, fully responsive website for a premium coffee shop, designed to showcase a brand's identity, menu, and customer reviews.

## ✨ Features

-   **Fully Responsive Design:** Optimized for all devices (desktops, tablets, and mobile phones).
-   **Modern & Aesthetic UI:** Clean, dark-themed layout with a warm primary color (`#bb9457`) for an inviting coffee shop feel.
-   **Smooth Animations:** Engaging "float" animations on hero and about section images.
-   **Interactive Elements:** Hover effects on menu cards, review cards, and buttons to enhance user experience.
-   **Well-Structured Sections:**
    -   **Hero Section:** Catchy headline and call-to-action.
    -   **About Us:** Brand story and key metrics (years of experience, happy customers).
    -   **Menu:** Visually appealing product cards displaying coffee items with prices.
    -   **Customer Reviews:** Testimonials section with star ratings and user avatars.
    -   **Footer:** Copyright information and social media links.
-   **Accessibility:** Includes `aria-label` attributes on interactive elements for better screen reader support.
-   **Performance Optimized:** Uses `loading="lazy"` for images to improve page load speed.

## 🛠️ Technologies Used

-   **HTML5** - Semantic markup for structure.
-   **CSS3** - Custom styling, animations, and variables.
-   **Bootstrap 5** - For responsive grid system, navbar, and components.
-   **Bootstrap Icons** - For star ratings and social media icons.
-   **Google Fonts (Poppins)** - For modern and clean typography.
